# Аудит сайта АСК «Луч»

Проверено 24 октября 2026. Цель — WCAG 2.2 AA для интерфейса, быстрая статическая загрузка и готовность к GitHub Pages. Это инженерная проверка, а не сертификат соответствия.

## Измерения

Lighthouse 13.5.0, Chrome headless, мобильный лабораторный профиль, локальный сервер. До изменений: Performance 80, Accessibility 96, Best Practices 100, SEO 92. Последний запуск сборки из /ASK/: **Performance 99, Accessibility 100, Best Practices 100, SEO 100**. В промежуточных запусках Performance колебался от 97 до 99.

Начальный сетевой объём: 617 262 → 225 987 байт (**−63,4%**). FCP: 3,3 → 1,4 с. LCP: 3,8 → 2,2 с. CLS: 0. Это один локальный сравнительный сценарий; опубликованный сайт, реальные устройства, INP и полевые Core Web Vitals необходимо проверять отдельно. Локальный сервер не моделирует CDN-сжатие и кеширование GitHub Pages.

Полный результат: [reports/lighthouse.json](reports/lighthouse.json). Проверки axe: [reports/axe-summary.json](reports/axe-summary.json). После этого измерения добавлена только блокировка прокрутки фона видеодиалога и синхронизация состояния details; сетевые зависимости и оформление не менялись.

## Исправления доступности

- Уточнены подписи ссылок логотипа, семантика схемы оборудования, skip-link и фокус после перехода к секции.
- Мобильное меню исключает фон из фокуса и дерева доступности через inert. Закрытое меню недоступно для фокуса. Escape, возврат фокуса, Tab/Shift+Tab и стабильная ширина страницы проверены.
- Нативный dialog делает фон инертным, имеет заголовок и подписанную кнопку закрытия. Escape закрывает видео, воспроизведение останавливается, фокус возвращается на ссылку. Прокрутка фона заблокирована.
- Аккордеон сохраняет нативные details/summary. Раскрытие и сворачивание анимированы за 200 мс, быстрые повторные клики корректно меняют направление. При reduced motion анимация отключена.
- Основные цели нажатия имеют высоту не менее 44 px. Фокус контрастен на светлых и тёмных областях; предусмотрены forced colors.
- Меню, ссылки контактов, аккордеон и открытие MP4 доступны без JavaScript. Письмо можно составить с JS или использовать обычную ссылку email.
- Проверены ширины 320, 375, 440, 560, 768, 900, 1024 и 1440 px, отсутствие сдвигов при открытии меню, изменение высоты окна, увеличенные текстовые интервалы и reflow 320 CSS px.
- axe-core 4.11.0: 0 автоматических нарушений в пяти состояниях — десктоп, 320 px, мобильное меню, раскрытый FAQ, видеодиалог. Проверялись теги WCAG 2 A/AA, 2.1 A/AA, 2.2 AA и best practice.

## Оптимизация

- Нет внешних запросов Google Fonts: локальные переменные WOFF2 для кириллицы и латиницы, font-display:swap. Оба набора содержат используемые начертания.
- Hero WebP около 75 КБ с preload и fetchpriority=high. Изображения ниже первого экрана — адаптивные WebP 480/960 с размерами, lazy loading и async decoding.
- CSS объединяется и минифицируется, JS минифицируется и подключается с defer. В начальной загрузке нет Fancybox, IMask или видео.
- Вместо 142 КБ Fancybox — нативный видеодиалог. Маска телефона загружается только при первом фокусе.
- MP4 сохранён без потери качества и загружается по запросу; preload=none. В файле moov уже находится перед mdat (fast start), перекодирование не потребовалось. Размер около 8,8 МБ не включён в начальную загрузку.
- Нет периодических таймеров, аналитических SDK, cookies и скрытой отправки контактных данных.

## SEO и безопасная публикация

Сборка формирует canonical, og:url, og:image, размеры и alt изображения, sitemap.xml, robots.txt, .nojekyll и 404 с noindex. Сохранены русский lang, уникальный title, description, логическая структура заголовков и JSON-LD Organization без вымышленных рейтингов или адресов. Публичный адрес берётся из SITE_URL, по умолчанию https://ikatenev.github.io/ASK/.

PHP, PHPMailer, SMTP и конфигурация секретов удалены. Страница не заявляет об отправке заявки, которой не было. Контактная форма только готовит mailto-письмо или копирует текст по нажатию пользователя. Нет внешнего обработчика формы, которому могли бы незаметно уйти данные.

GitHub Actions собирает и проверяет dist по списку разрешённых файлов; тесты, документы, исходники и конфигурация разработки не публикуются. Действия закреплены SHA, права на запись ограничены deploy job. HTML содержит CSP без unsafe-inline/unsafe-eval: JSON-LD разрешён конкретным SHA-256. Серверные настройки, заголовки и HTTP-кеш GitHub Pages не имитируются неподдерживаемыми .htaccess или метатегами.

В единственной локальной Git-ревизии проверены известные прежние места секретов (mail.php, telegram.php, .env); значений токена и SMTP-пароля не найдено. Это не полный аудит удалённых refs и не отменяет рекомендацию отозвать любые ранее раскрытые реальные ключи.

## Границы проверки

- **Видео:** axe отмечает необходимость ручной проверки субтитров. Не предоставлена достоверная расшифровка речи/значимых звуков и содержания, поэтому субтитры и аудиоописание не выдумывались. Для полного заявления о WCAG AA нужно проверить ролик вручную и добавить соответствующие материалы. Краткое описание сценария рядом с видео не является полной расшифровкой.
- Нужна ручная проверка NVDA/VoiceOver и Safari/iOS. Автоматические сценарии выполнялись в Chromium; наличие native dialog/inert и резервных ссылок уменьшает риск, но не заменяет такие проверки.
- SEO-баллы не гарантируют индексацию. После публикации проверить публичные canonical, sitemap и социальное превью, при необходимости зарегистрировать сайт в Search Console. robots.txt внутри /ASK/ не управляет корнем домена github.io.
- Деплой не выполнялся. Инструкция находится в README.md.


## Исправление CLS после проверки опубликованного сайта

В предоставленном отчёте Lighthouse 13.4.1 с GitHub Pages CLS равнялся 0,48474045; 0,48473490 приходилось на мобильную навигацию, а не на изображения. Причина — CSS показывал резервную навигацию в потоке страницы до добавления класса js отложенным main.js. На локальной быстрой загрузке этот промежуточный кадр не попадал в прошлые измерения. Это дефект прежней реализации и недостаток предыдущей проверки холодной загрузки.

До исправления тест с задержкой main.min.js на 2500 мс воспроизвёл CLS 0,48472546. Теперь небольшой синхронный bootstrap в head устанавливает режим JS до CSS и первого layout. Резервная навигация по-прежнему видна при отключённом JS. CSP разрешает bootstrap и JSON-LD по точным SHA-256 без unsafe-inline; оба хеша проверяются тестом сборки. Добавлен preload латинского набора шрифта, так как он используется также для пробелов и знаков.

Новый тест tests/cold-load.cjs (412×823 CSS px, DPR 1,75):
- main.js задержан на 2500 мс: CLS 0;
- main.js задержан на 2500 мс, оба шрифта на 1800 мс: CLS около 0,0014;
- браузерных ошибок и блокировок CSP нет, меню после загрузки работает.

Результат: reports/cold-load.json. Повторный локальный Lighthouse: reports/lighthouse-cls-fix.json. Эти результаты относятся к исправленной локальной сборке; проверка GitHub Pages требует нового push и завершения deploy. Предыдущая публикация пока не содержит исправления.

В отчёте опубликованного сайта Cache-Control соответствует TTL 600 секунд. Его устанавливает GitHub Pages; произвольные HTTP-заголовки кеширования из файлов сайта не настраиваются. Этот пункт не исправляется фиктивными метатегами или .htaccess и не является причиной большого CLS.
